# Q — Marketing Website

Landing page for **Q**, a behavioral finance app that reads your bank SMS on-device
and turns your spending into scores, streaks, a financial persona, and an offline
AI coach.

## What's here

- `index.html` — the full marketing site (single file: HTML, CSS, and JS inline).
  No build step required, just open it in a browser or deploy it as a static site.

## Status

This site describes a product still in active development. Pricing and feature
details shown are illustrative and subject to change before launch. The waitlist
form is not yet wired to a live backend.
